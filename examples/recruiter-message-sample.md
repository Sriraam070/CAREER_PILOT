### Why this works
- **Recruiter must-haves first:** 3+ yrs Python, LLMs, RAG, PostgreSQL, AWS, and remote India/notice period all show up in the first lines.
- **Hard numbers mapped to the JD:** "40k users / −28% tickets" proves *own RAG end-to-end*. "2M req/day FastAPI on AWS" proves *ship Python services*.
- **Honest about gaps:** Kubernetes and agents aren't claimed. The follow-up turns the agent gap into a "currently building" signal, but only send that line once the project actually exists.
